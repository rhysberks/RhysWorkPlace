# RhysWorkPlace
One-stop development environment with AI capabilities, based on Ollama local models. The program comes with a sleek GUI inspired by iOS 27, hardware &amp; software suggestions, bottleneck analysis, adjustable gaming overlays, and AI-driven file organization system. Entirely customizable and made to run on models optimized for your hardware. 

A fully integrated AI-powered workspace for developers, creators, and PC enthusiasts with a snazzy new look and rich, local AI features. An interface designed new from the ground up, inspired by iOS 27 but built for the desktop.

According to Ollama and the local AI, the workspace provides an simple GUI that allows customers to utilize and work with the native hosted fashions without necessitating them to work solely within the command line interface. It permits customers to choose their own models to work with.

A system that can perform analysis of your computer hardware and software and can provide helpful advices according to its performance and configuration. The system will identify the potential performance bottlenecks, its probable percentage and will provide you with actionable insights how to enhance your performance. The issue can be with cpu, gpu, ram, storage, thermals or software configuration. The bottom line is to provide useful and memorable recommendations instead of typical tips.

Desktop Gaming custom overlay for the PC. Monitor your gameplay while gaming with real-time system resource usage and in-game overlays. You should be able to view all the data you need to track as you are using your PC while gaming on it.

# Setup

1. Download the main folder
2. Open terminal and paste the folder path (ex : /cd C:\Users\YourUsername\Downloads\RhysOverlay
3. Run These commands : 
``npm install``
``npm run dev``
The app will be launched within 5-10 seconds depending on your hardware 

Note : This is V1 and has alot of bugs, It will be fixed soon in V1.1 also if you find any bug please report to my discord : shinoeba
